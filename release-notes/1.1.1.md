# 165 Armer 1.1.1

## What's changed since 1.1.0

- **Lock screen at 120 Hz** (issue #26), in Settings. Set the phone's
  **Settings → Display → Screen refresh rate** to **Standard** and turn this
  on: app switching and the notification shade run at the armed rate (165 Hz),
  and the lock screen stays at 120 Hz instead of dropping to 60. No adb needed.
  See the README for the steps.
- **165 Hz idles to 33 Hz on ColorOS 17**, down from 55 on ColorOS 16. The
  app now uses the right figure for your phone.

**Upgrading:** signed with the same key as 1.1.0, so it installs over it and
keeps your armed apps.
