# 165 Armer 1.1.4

## What's changed since 1.1.3

- **Split view and floating windows at the armed rate** (issue #32). With
  two apps on screen, in split view or with one as a floating window, the
  screen dropped to 120 Hz whatever was armed. It now stays at the armed
  rate, for example 165 Hz, and goes back to normal when you return to one
  app. This needs **Usage access** (the row at the top of Settings), so the
  app can see both apps.
- **New Help page.** Six short cards on using the app instead of eighteen on
  how it works inside.

**Upgrading:** signed with the same key as 1.1.3, so it installs over it and
keeps your armed apps and settings.
