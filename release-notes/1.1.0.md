# 165 Armer 1.1.0

Rootless per-app refresh-rate unlock for OnePlus phones. This release adds a
185 Hz tier for the OnePlus 16, fixes arming on the OnePlus Nord 6, and adds
Simplified Chinese with an in-app language switcher.

**[Download arm165.apk](https://github.com/tryptz/Force165hz-Oneplus-15-NoRoot/releases/download/1.1.0/arm165.apk)**
· Android 10+ · versionCode 13

## Highlights

### 185 Hz
- New **185** option in the rate selector, the per-app picker and the widget.
- The OnePlus 16 runs it as a real 185 Hz mode (rate id 8, read from its own OTA).
- On a phone whose panel tops out at 165, such as the OnePlus 15, picking 185
  runs at **165** instead, and the app tells you so. Nothing breaks and
  nothing needs resetting.

### OnePlus Nord 6 works now (#17)
- Every arm used to fail with *"Parcel data not fully consumed"*. The Nord 6
  numbers the vendor call differently (transaction 11, not 12).
- The app now asks the phone's own firmware which number it uses, once at
  launch, before you tap anything.
- If the firmware won't say, it tests safely against a package nobody has
  installed. On a numbering nobody has seen yet, it searches the interface
  for the call that behaves like the vote.
- **Settings** shows how the call was found: *named by the build*, *its
  proxy*, *probed*, *swept* or *assumed*. That is useful to include in a bug
  report.

### Languages
- Full **Simplified Chinese (简体中文)** translation of the main screen,
  dialogs, help, settings, smoothness test and games page.
- New **Language** row in Settings: *System default*, *English* or *简体中文*,
  independent of the phone's language.
- On Android 13+ this uses the system's own per-app language setting, so it
  also appears under **Settings → Apps → 165 Armer → Language**.

## Upgrading

- **This release is signed with a new, permanent release key.** If Android
  says *"App not installed"* or *"package conflicts with an existing
  package"*, your current copy was signed with the old key. **Uninstall it
  first, then install 1.1.0.** Uninstalling clears the armed-app list, so
  note which apps you had armed before you do.
- From 1.1.0 on, every release uses this key, so later updates install
  straight over it.

## Known issues

- On some builds the vote is accepted but the panel stays at 120. The log
  shows `extreme=`, `vendorGame=` and `registerGame(...) added=` to tell
  whether the vote lost or was never eligible. Include those lines in a report.
- 185 Hz is enabled by model number. Only the Chinese OnePlus 16 (`PYB110`) is
  confirmed so far. A OnePlus 16 with another model number will run 185 at
  165 until its number is added. Please report your model (**Settings →
  About device → Model**).
- Below Android 13, the widget and the notification may stay in the phone's
  language after you switch the app's language.
